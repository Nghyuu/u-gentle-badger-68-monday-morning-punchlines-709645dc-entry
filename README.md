## What it does

`main.ts` writes a single original joke about Monday mornings — at most 200 characters, one line — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node standard library only; no dependencies, no network, no data files.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
